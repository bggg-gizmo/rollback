# Security Policy

## Supported release

Roll Backer 1.0.1 is the supported public release.

## Reporting a vulnerability

Please do not open a public issue for suspected security vulnerabilities.

Use GitHub private vulnerability reporting for this repository when enabled. If that feature is unavailable, contact the repository owner privately through an established trusted channel.

Include the affected component, reproduction steps, security impact, and only the proof-of-concept material necessary to reproduce the issue. Do not include unrelated secrets or personal data.
